# Tavern Trivia

A Hearthstone Battlegrounds trivia quiz with 1,000 questions about minions, heroes, armor (Solo and Duos), Hero Powers, Buddies, quest rewards, trinkets, Tavern spells and anomalies.

- **Solo:** 20 random questions.
- **Co-op:** create a game to get a 5-letter code. A friend joins with the code, and you both answer the same 20 questions while seeing each other's picks live.

Questions were generated from the Hearthstone card data (client build of 3 November 2026).

Fan-made, not affiliated with Blizzard Entertainment.
